# [`plotDistributions`](https://github.com/cwendorf/plotDistributions)

## Reference

This section is the reference for backcalc. Each page documents one exported function, including usage, arguments, and return values.

### Binomial Distribution

- [binom.cdf](./binom.cdf.md): Cumulative distribution function (CDF) for the binomial distribution.
- [binom.pdf](./binom.pdf.md): Probability mass function (as a PDF) for the binomial distribution.

### Chi-Squared Distribution

- [chisq.cdf](./chisq.cdf.md): Cumulative distribution function (CDF) for the chi-squared distribution.
- [chisq.pdf](./chisq.pdf.md):Probability density function (PDF) for the chi-squared distribution.

### F Distribution

- [f.cdf](./f.cdf.md): Cumulative distribution function (CDF) for the F distribution.
- [f.pdf](./f.pdf.md): Probability density function (PDF) for the F distribution.

### Normal Distribution

- [norm.cdf](./norm.cdf.md): Cumulative distribution function (CDF) for the normal distribution.
- [norm.pdf](./norm.pdf.md): Probability density function (PDF) for the normal distribution.

### Studentized Range Distribution

- [q.cdf](./q.cdf.md): Cumulative distribution function (CDF) for the Studentized range distribution.
- [q.pdf](./q.pdf.md): Probability density function (PDF) for the Studentized range distribution.

### Student's t Distribution

- [t.cdf](./t.cdf.md): Cumulative distribution function (CDF) for Student's t-distribution.
- [t.pdf](./t.pdf.md): Probability density function (PDF) for Student's t-distribution.
