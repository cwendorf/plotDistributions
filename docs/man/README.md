# [`plotDistributions`](https://github.com/cwendorf/plotDistributions)

## Reference

This section is the reference for backcalc. Each page documents one exported function, including usage, arguments, and return values.

### Binomial Distribution

- [Plot the CDF of the Binomial Distribution](./binom.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the binomial distribution, with optional visual indicators of probability differences between specified limits or quantiles.
- [Plot the PDF of the Binomial Distribution](./binom.pdf.md): Generates a plot of the probability mass function (treated as a PDF) for the binomial distribution, with optional shaded area between specified limits or quantiles.

### Chi-Squared Distribution

- [Plot the CDF of the Chi-Squared Distribution](./chisq.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the chi-squared distribution, with optional annotations showing cumulative probability differences between limits or quantiles.
- [Plot the PDF of the Chi-Squared Distribution](./chisq.pdf.md): Generates a plot of the probability density function (PDF) for the chi-squared distribution, with optional shading between specified limits or quantiles.

### F Distribution

- [Plot the CDF of the F Distribution](./f.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the F distribution, optionally annotating cumulative probability differences between specified limits or quantiles.
- [Plot the PDF of the F Distribution](./f.pdf.md): Generates a plot of the probability density function (PDF) for the F distribution, with optional shaded areas between specified limits or quantiles.

### Normal Distribution

- [Plot the CDF of the Normal Distribution](./norm.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the normal distribution, optionally highlighting cumulative probability differences between bounds or quantiles.
- [Plot the PDF of the Normal Distribution](./norm.pdf.md): Generates a plot of the probability density function (PDF) for the normal distribution, with optional shaded regions defined by limits or quantiles.

### Studentized Range Distribution

- [Plot the CDF of the Studentized Range Distribution](./q.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the Studentized range distribution, optionally highlighting probability differences between specified limits or quantiles.
- [Plot the PDF of the Studentized Range Distribution](./q.pdf.md): Generates a plot of the probability density function (PDF) for the Studentized range distribution, with optional shaded regions based on limits or quantiles.

### Student's t Distribution

- [Plot the CDF of the Student's t-Distribution](./t.cdf.md): Generates a plot of the cumulative distribution function (CDF) for the Student's t-distribution, with optional visual indicators of probability differences between specified limits or quantiles.
- [Plot the PDF of the Student's t-Distribution](./t.pdf.md): Generates a plot of the probability density function (PDF) for the Student's t-distribution, with optional shaded area between specified limits or quantiles.
